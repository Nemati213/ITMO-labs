# Лабораторная работа №1 по веб-программированию

Страница проверяет попадание точки с координатами `X` и `Y` в заданную область при выбранном значении `R`.

## Что реализовано

- форма для выбора `X`, ввода `Y` и выбора `R`;
- проверка введённых значений на JavaScript;
- отрисовка координатной плоскости и области через Canvas;
- вычисление попадания точки в область;
- вывод результатов в таблицу;
- сохранение истории проверок в `localStorage`;
- отображение даты и времени в русской локализации.

## Вариант

- `X` — checkbox со значениями от `-3` до `5`;
- `Y` — текстовое поле со значениями от `-5` до `3`;
- `R` — кнопки со значениями от `1` до `5`.

Область состоит из четверти круга в первой четверти, треугольника во второй четверти и прямоугольника в четвёртой четверти.

## Структура

- `index.html` — разметка страницы и CSS;
- `script.js` — валидация, Canvas, проверка попадания и работа с `localStorage`;
- [`task/УСЛОВИЕ.md`](task/УСЛОВИЕ.md) — полное условие лабораторной;
- [`task/variant-area.png`](task/variant-area.png) — схема области и параметры варианта.

## Запуск

Открыть `index.html` в браузере. Дополнительная сборка и установка зависимостей не требуются.
